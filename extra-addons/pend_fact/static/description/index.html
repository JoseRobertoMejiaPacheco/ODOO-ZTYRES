Pendiente de Facturar

Detecta en tiempo real qué entregas no han sido facturadas

📦 ¿Qué hace?

Compara las entregas de stock con las facturas emitidas y muestra únicamente las líneas donde la cantidad entregada supera la cantidad facturada, considerando devoluciones y notas de crédito.

  • 🗓 Filtro por año, mes o rango de fechas
  • 🔍 Búsqueda por venta, cliente o producto
  • 👤 Filtro por vendedor
  • 🔄 Auto-refresco cada 3 horas
  • 📜 Tabla con scroll y header fijo

🔎 Análisis de pedido

Ingresa cualquier número de venta para ver el desglose completo línea por línea: entregado, devolución, facturado, NC y pendiente, aunque la orden no aparezca en la lista de pendientes.

⚠️ NC no ligadas

Detecta automáticamente notas de crédito que no están vinculadas a ninguna línea de venta y muestra un aviso con botón para abrirlas en contabilidad.

🧮 Lógica de cálculo

Entrega neta    = Entregas outgoing − Devoluciones incoming
Facturado neto = Facturas out_invoice − Notas crédito out_refund
Pendiente      = Entrega neta − Facturado neto

El cálculo se realiza con SQL nativo usando subqueries independientes por fuente, evitando productos cartesianos. El agrupamiento por (venta, producto) ocurre en la BD para manejar correctamente órdenes con múltiples líneas del mismo producto.

⚙️ Información técnica

  • Odoo: 16 Enterprise
  • Módulos requeridos: sale_management, account, stock
  • Frontend: OWL 2 con template inline — sin dependencias externas
  • Backend: controlador JSON-RPC + SQL nativo para máximo rendimiento
  • Localización MX: compatible con l10n_mx_edi_cfdi_uuid
